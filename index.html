What you get on the Arcadyan AW1000

  • Phone on the router. Caller id, call waiting, hold, three-way join, call log, speed dial.
  • 5G that recovers by itself. QModem, auto-dial, dual-stack IPv4/IPv6, SMS, TTL control.
  • A modern interface. Apex theme in dark and light, usable from a phone.
  • LEDs that mean something. 5G SA or NSA, signal quality, a real internet check, night mode.
  • Tools, off by default. Passwall, WireGuard, OpenVPN, Tailscale, AdGuard Home and more.
  • Verifiable builds. Built on GitHub Actions from pinned sources, with checksums.

Get started

  1. Check your flash layout. The image needs the expanded layout.
  2. Install OpenWrt on the AW1000 with UART and TFTP, then update with sysupgrade.
  3. First boot, then set up the 5G modem and the phone port.
  4. Recover the router if something goes wrong.

Frequently asked questions

What is CleanWRT?

CleanWRT is an open build of OpenWrt 25.12 for the Arcadyan AW1000 5G router (Qualcomm IPQ8072, Quectel RG500Q-EA modem). It adds a working RJ11 phone port (AWvoice), the Apex interface theme, front-panel LED management and a set of optional tools that stay off until you enable them.

Does OpenWrt run on the Arcadyan AW1000?

Yes. CleanWRT is OpenWrt 25.12.5 built for the AW1000. The image needs the expanded flash layout (the rootfs partition must be at least 0x08000000), so check /proc/mtd on your router before you flash. The documentation explains how.

Can I use a normal phone on the AW1000 RJ11 port?

Yes, with AWvoice. An ordinary desk phone on the RJ11 socket can make and take calls over your SIM using VoLTE, with caller id, call waiting, hold, a three-way join, a call log and speed dial. The modem must be in PCM slave mode, and the phone port is not meant for emergency calls.

How do I install CleanWRT on the AW1000?

The first install from the stock firmware needs a serial console (UART) and a TFTP server. Once the router runs OpenWrt, later updates use sysupgrade. Read the installation and recovery guides before you start.

Is CleanWRT free?

Yes. The build configuration, patches and scripts are GPL-2.0-only and free of charge. Bundled packages keep their own licences; QModem carries an added non-commercial clause, so read it before any business or paid use.

Is CleanWRT affiliated with the OpenWrt project?

No. CleanWRT is an independent build, powered by OpenWrt, and is not affiliated with or endorsed by the OpenWrt project.
